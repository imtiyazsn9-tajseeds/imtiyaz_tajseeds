Baad Mein Website Manage Karne Ki Aasan Guide

1. Login ID & Password:

Admin ID aur Password server par set hote hain (ADMIN_ID aur ADMIN_PASSWORD). Password badalne ke liye server chalate waqt naya ADMIN_PASSWORD dein. Password kisi ke saath share na karein.

2. Website Par Admin Login Kahan Hai?

Admin Login ab website par 3 aasan jagahon par uplabdh hai:
- Footer Bottom Bar: Sabhi pages ke footer mein niche "Admin Portal" link par click karein.
- Mobile Drawer: Phone mein menu kholte hi niche "Admin Portal Login" button milega.
- Top Announcement Bar: Computer par upar daayein taraph "Admin Portal" link se khol sakte hain.

3. Home Page Ke Products Kaise Badlein?

Upar "Home Page Seeds" tab par click karein. Jis-jis beej par aap click karenge, woh select (green) ho jayega. Fir upar "Save Changes" par click kar dein. Wahi beej Home page par dikhne lagenge!

4. Naya Seed Product Kaise Jodein Aur Photo Upload Karein?

"All Seeds Catalog" tab mein jayein aur "Add New Seed" button dabayein. Wahan aapko "Upload Photo" ka option milega. Apne phone ya computer se seed pouch ki photo chunein, details bharein aur Save kar dein.

5. Gallery Photos, Description Aur Section Kaise Badlein Ya Hatayein?

"Photos & Gallery" tab par jayein:
- Nayi Photo Upload Karein: "Add New Photo" button dabayein. Apne phone ya PC se photo chunein, category select karein (Farm & Trials, Processing Plant, Warehouse, Packaging & Security), title aur description likhein aur Save kar dein.
- Existing Photo / Description Edit Karein: Kisi bhi photo card par "Edit / Change Photo" button dabayein aur details update kar dein.
- Photo Hatayein (Delete): Kisi bhi unwanted photo card par "Delete" button dabakar use hata dein.
- Sabhi badlav ke baad upar ya niche "Save Gallery Changes" button dabana na bhulein!
